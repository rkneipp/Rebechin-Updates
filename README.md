# Rebechin Updates

This repository is the public update and distribution channel for Rebechin.

Rebechin application source code is maintained separately in the private canonical source repository and is not published here. Downloadable artifacts are Apple-signed builds. Release metadata in latest.json is intended for Rebechin's credential-free native update checker.

Public releases contain only signed application artifacts and minimal distribution metadata. They do not contain source code, runtime databases, Transport operational data, personal data, fiscal data, credentials, GitHub tokens, Apple certificates or private keys.

For the current release metadata, see latest.json. Verify the published ZIP SHA-256 before installation when desired.
